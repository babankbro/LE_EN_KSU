## คำอธิบายรายวิชา

### ภาษาไทย

องค์ประกอบและการทำงานของระบบคอมพิวเตอร์ การคิดเชิงคำนวณและการออกแบบขั้นตอนวิธี การเขียนโปรแกรมด้วยภาษาคอมพิวเตอร์ระดับสูง ชนิดข้อมูล ตัวแปร นิพจน์ โครงสร้างควบคุม ฟังก์ชัน อาเรย์ และแฟ้มข้อมูล การดีบักและการทดสอบโปรแกรมเบื้องต้น การควบคุมเวอร์ชันเบื้องต้น การใช้เครื่องมือปัญญาประดิษฐ์ช่วยเขียนโปรแกรมและการตรวจสอบความถูกต้องของโค้ด ปฏิบัติการเขียนโปรแกรม

### English

Components and operation of computer systems; computational thinking and algorithm design; programming using a high-level programming language; data types, variables, expressions, control structures, functions, arrays, and files; basic program debugging and testing; fundamentals of version control; use of artificial intelligence (AI) tools to assist in programming and verification of code correctness; programming laboratory
