# วิธีสอนและวิธีประเมินราย PLO (หมวด 5.1)

| PLO | วิธีการจัดการเรียนการสอน | วิธีการประเมินผล |
|---|---|---|
| [[PLO_LE1]] | - ฝึกคำนวณทางคณิตศาสตร์/วิทยาศาสตร์ และโจทย์วิศวกรรม - วิเคราะห์สาเหตุด้วย Systems Thinking - ใช้ข้อมูลคำนวณตัวชี้วัด เปรียบเทียบทางเลือกในงานขนส่ง คลังสินค้า และโครงงาน | - ข้อสอบคำนวณพร้อมแสดงขั้นตอน - ผังความสัมพันธ์และรายงานวิเคราะห์ปัญหา - งานคำนวณต้นทุน/เวลา/KPI รายงานเลือกทางเลือกพร้อมเหตุผลและตรวจความถูกต้องข้อมูล |
| [[PLO_LE2]] | - กรณีศึกษาความเสี่ยง ข้อกำหนดด้านความปลอดภัย - วิเคราะห์ผลกระทบเศรษฐกิจ สังคม สิ่งแวดล้อม - อภิปรายสถานการณ์จริยธรรมและประเด็นสาธารณะก่อน/ระหว่างสหกิจ | - แบบประเมินความเสี่ยงและการปฏิบัติตามกฎหมาย/มาตรฐาน - รายงานเปรียบเทียบผลกระทบและความยั่งยืน - Rubric การตัดสินใจและเหตุผลจริยธรรมจากสถานการณ์จำลอง/สหกิจ |
| [[PLO_LE3]] | - ฝึกอธิบายแบบวิศวกรรมและเขียนรายงานภาษาไทย - ฝึกศัพท์/การอ่านและพูดเขียนภาษาอังกฤษ - มอบหมายงานทดลองและโครงงานแบบแบ่งบทบาทสมาชิก/ผู้นำ | - แบบประเมินรายงานและนำเสนอภาษาไทย - งานพูด/เขียนหรือบทคัดย่อภาษาอังกฤษ - Rubric บทบาท ความรับผิดชอบ การประสานงานและหลักฐานส่งมอบงานกลุ่ม |
| [[PLO_LE4]] | - ให้สำรวจช่องว่างทักษะ ตั้งเป้าหมายการเรียนรู้ - ค้นคว้าเทคโนโลยี/เครื่องมือใหม่ด้วยตนเอง - ประเมินตนเองจากงานโปรแกรม GIS โครงงานและสหกิจ พร้อมสะท้อนผล | - แผนเรียนรู้รายบุคคลและ Gap Analysis - ชิ้นงานที่ใช้เทคโนโลยีที่ศึกษาด้วยตนเองพร้อมหลักฐานการค้นคว้า - Learning Log/ Portfolio และ Self-assessment พร้อมแผนปรับปรุง |
| [[PLO_IE1]] | - ใช้โจทย์ออกแบบระบบงาน/ผลิตภัณฑ์/ผังโรงงานจากข้อกำหนด - พัฒนาแบบหรือทางเลือก และพิจารณาความปลอดภัย คุณภาพ ต้นทุนและวัฏจักรชีวิต | - ใบวิเคราะห์ข้อกำหนดและข้อจำกัด - ผลงานออกแบบผัง/ระบบ/ต้นแบบตามโจทย์และ Rubric - ตารางเปรียบเทียบแบบ/วิเคราะห์ต้นทุนคุณภาพความเสี่ยงและ LCA ตามขอบเขตโจทย์ |
| [[PLO_IE2]] | - กำหนดคำถามวิจัย ตัวแปร แผนการทดลอง - ลงมือทดสอบวัสดุ/ชิ้นงาน/ระบบ - วิเคราะห์ข้อมูลพร้อมอภิปรายข้อผิดพลาดและความไม่แน่นอน | - ข้อเสนอแผนทดลองหรือวิธีเก็บข้อมูล - แบบตรวจงานทดลองและสมุดบันทึกผลจริง - รายงานวิเคราะห์ผล ข้อจำกัดและข้อสรุปพร้อมหลักฐาน |
| [[PLO_IE3]] | - ฝึกเลือกแบบจำลองสำหรับปัญหาการผลิต - ใช้ OR และปฏิบัติการระบบอัตโนมัติแก้โจทย์ - ตรวจความสมเหตุสมผลของผลและข้อจำกัดของแบบจำลอง | - ใบเลือกวิธีเชิงปริมาณพร้อมเหตุผล - โมเดล LP/ Assignment/ Queue/ Simulation หรือผลทดลองระบบอัตโนมัติ - Rubric ตรวจสอบผลลัพธ์ Sensitivity/ข้อจำกัด |
| [[PLO_IE4]] | - ฝึกทำแผนผลิตและโครงการผังโรงงาน กำหนดกิจกรรม ผู้รับผิดชอบ งบประมาณและระยะเวลา - บริหารการดำเนินงานจำลองและทบทวนผล | - แผนงานและกำหนดทรัพยากร - หลักฐานจัดสรรงาน/ประสานทีมในสถานการณ์จำลอง - รายงานเทียบผลจริงหรือสถานการณ์จำลองกับ KPI เวลา งบประมาณ คุณภาพ และความเสี่ยง |
| [[PLO_IE5]] | - วิเคราะห์ปัญหาจากผู้เกี่ยวข้องในสถานประกอบการ/ ชุมชน - เสนอแนวทางปรับปรุงงานผลิต คุณภาพหรืออัตโนมัติ - ทดสอบความเป็นไปได้ทางเทคนิค เศรษฐกิจ ความยั่งยืน | - รายงานวิเคราะห์ปัญหาและความต้องการ - แบบร่างแนวทางนวัตกรรมหรือต้นแบบพร้อมเกณฑ์คุณค่า - รายงาน Feasibility/ผลประโยชน์-ต้นทุนและผลกระทบ |
| [[PLO_SC1]] | - วิเคราะห์การไหลจากจัดซื้อ ผลิต สินค้าคงคลังถึงกระจายสินค้า - ใช้โจทย์ออกแบบโซ่อุปทาน/ แผนบูรณาการ - ประเมินทางเลือกตามต้นทุน ระดับบริการ และความเสี่ยง | - แผนภาพการเชื่อมโยงกิจกรรมพร้อมหลักฐาน - แผน/แบบระบบโซ่อุปทานตามข้อจำกัด - ตารางวิเคราะห์ต้นทุน ระดับบริการ และความเสี่ยง |
| [[PLO_SC2]] | - ฝึกวางแผนอุปสงค์-สินค้าคงคลัง ขนส่งและอุปกรณ์คลัง - ฝึกคำนวณ KPI และออกแบบแนวทางปรับปรุงด้วยโจทย์ปฏิบัติ | - แผนดำเนินงานเชิงปริมาณ - ผลคำนวณ KPI ต้นทุน เวลา ทรัพยากร/ บริการ - รายงานเปรียบเทียบก่อน–หลังหรือทางเลือกปรับปรุง |
| [[PLO_SC3]] | - ใช้ข้อมูลโลจิสติกส์และเครื่องมือดิจิทัล/ แบบจำลอง - วิเคราะห์และแปลผลเพื่อเสนอการตัดสินใจ - ตรวจความครบถ้วนข้อมูลและข้อจำกัดเครื่องมือ | - ไฟล์งานวิเคราะห์เชิงปริมาณ/แบบจำลอง - Dashboard หรือรายงานข้อเสนอประกอบผลวิเคราะห์ - Checklist คุณภาพข้อมูลและอภิปรายความน่าเชื่อถือ/ข้อจำกัด |
| [[PLO_SC4]] | - ศึกษาปัญหาหรือความต้องการของสถานประกอบการ/ชุมชน - พัฒนาข้อเสนอ โลจิสติกส์สีเขียว/ระบบสินทรัพย์ - วิเคราะห์ความเป็นไปได้ทางเศรษฐกิจ สังคม สิ่งแวดล้อม | - รายงานสถานการณ์ปัญหาและผู้เกี่ยวข้อง - ข้อเสนอโครงการปรับปรุงพร้อมมาตรการใช้ทรัพยากรคุ้มค่า - เกณฑ์และรายงานประเมิน Feasibility/ ผลกระทบ 3 มิติ |
