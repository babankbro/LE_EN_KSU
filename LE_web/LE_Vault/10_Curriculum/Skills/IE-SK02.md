## ทักษะย่อย (Sub-skill) และระดับความเชี่ยวชาญ (Proficiency Level)

### 1. การเลือกเครื่องมือและแบบจำลอง (Engineering Tool Selection)

- **ระดับความเชี่ยวชาญ:** ระดับ 2 (ประยุกต์ใช้)
- **คำอธิบาย:** เลือกเครื่องมือและแบบจำลองที่เหมาะกับปัญหาทางวิศวกรรม
- **CLO ที่เกี่ยวข้อง:**
    - [[EN-788-13006|การวิจัยการดำเนินงาน]] CLO1 — วิเคราะห์ลักษณะปัญหาทางวิศวกรรมอุตสาหการและเลือกวิธีการวิจัยการดำเนินงานหรือแบบจำลองทางคณิตศาสตร์ที่เหมาะสมกับปัญหาและข้อกำหนดที่กำหนด
    - [[EN-788-13005|การจัดการการผลิต]] CLO1 — เลือกใช้วิธีการวิเคราะห์เชิงปริมาณที่เหมาะสมกับปัญหาการจัดการการผลิต โดยพิจารณาข้อมูลและข้อจำกัดที่กำหนด
- **เครื่องมือ:** Mathematical Models, Optimization Tools
- **การประเมิน:** แบบฝึกวิเคราะห์และเลือกแบบจำลอง

### 2. การสร้างและประยุกต์ใช้แบบจำลอง (Modeling & Simulation)

- **ระดับความเชี่ยวชาญ:** ระดับ 3 (วิเคราะห์และบูรณาการ)
- **คำอธิบาย:** ประยุกต์แบบจำลองทางคณิตศาสตร์หรือการจำลองระบบเพื่อวิเคราะห์ปัญหา
- **CLO ที่เกี่ยวข้อง:**
    - [[EN-788-13006|การวิจัยการดำเนินงาน]] CLO2 — สร้างและประยุกต์ใช้แบบจำลองกำหนดการเชิงเส้น ปัญหาการมอบหมายงาน ตัวแบบพัสดุคงคลัง ตัวแบบการขนส่ง และการวิเคราะห์โครงข่ายงาน เพื่อวิเคราะห์และแก้ปัญหาวิศวกรรม อุตสาหการตามโจทย์ที่กำหนด
    - [[EN-788-13006|การวิจัยการดำเนินงาน]] CLO3 — ประยุกต์ใช้ทฤษฎีเกม ทฤษฎีแถวคอย และการจำลองสถานการณ์ในการวิเคราะห์ปัญหาและสนับสนุนการตัดสินใจทางวิศวกรรม อุตสาหการตามเงื่อนไขที่กำหนด
    - [[EN-788-13010|ปฏิบัติการวิศวกรรมอุตสาหการและระบบอัตโนมัติ]] CLO3 — ประยุกต์ใช้ระบบอัตโนมัติ ระบบไฮโดรลิกส์ ระบบนิวเมติกส์ หุ่นยนต์อุตสาหกรรมเบื้องต้น พีแอลซี และการควบคุมแบบลูปปิด เพื่อทดลองหรือจำลองการทำงานของระบบที่สนับสนุนการวางแผนและควบคุมการผลิตตามโจทย์ที่กำหนด
- **เครื่องมือ:** Spreadsheet Solver, Simulation Software หรืออุปกรณ์ระบบอัตโนมัติที่ใช้จริง
- **การประเมิน:** แบบจำลองและรายงานผลการทดลอง

### 3. การตรวจสอบผลลัพธ์และข้อจำกัดของแบบจำลอง (Model Verification & Evaluation)

- **ระดับความเชี่ยวชาญ:** ระดับ 3 (วิเคราะห์และบูรณาการ)
- **คำอธิบาย:** ตรวจสอบความถูกต้อง ความน่าเชื่อถือ และข้อจำกัดของแบบจำลองหรือเครื่องมือ
- **CLO ที่เกี่ยวข้อง:**
    - [[EN-788-13006|การวิจัยการดำเนินงาน]] CLO4 — ประเมินความถูกต้อง ความสมเหตุสมผล และข้อจำกัดของผลลัพธ์จากแบบจำลองหรือเทคนิคการหาคำตอบที่เหมาะสม เพื่อสรุปผลและเสนอแนวทางตัดสินใจทางวิศวกรรมอุตสาหการ
    - [[EN-788-13010|ปฏิบัติการวิศวกรรมอุตสาหการและระบบอัตโนมัติ]] CLO4 — ใช้เครื่องมือวัดเพื่อตรวจสอบและประเมินความถูกต้อง ความน่าเชื่อถือ และข้อจำกัดของผลลัพธ์จากระบบการผลิตหรือระบบอัตโนมัติที่ทดลอง
- **เครื่องมือ:** Model Verification, Sensitivity Analysis
- **การประเมิน:** รายงานตรวจสอบผลลัพธ์และการอภิปรายข้อจำกัด
