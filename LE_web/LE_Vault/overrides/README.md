# overrides · ค่าที่แก้หรือเติมด้วยมือ

> ใช้เมื่อเล่มผิดหรือขาด แต่ยังแก้ไฟล์ .docx ไม่ได้ ตัวสร้างข้อมูลเว็บ (`web/scripts/build-data.mjs`) จะอ่านไฟล์ในโฟลเดอร์นี้ทับค่าจาก `data/curriculum.json` และเว็บจะแสดงป้าย "แก้ไขจากเล่ม" ทุกจุดที่ถูก override (SRS: DP-07)

## รูปแบบไฟล์ (ร่าง ใช้กำหนดในขั้นที่ 2)

| ไฟล์ | ใช้แก้อะไร | ตัวอย่างข้อสังเกตที่ปิด |
|---|---|---|
| `plo_names.md` | เปลี่ยนชื่อสั้นภาษาอังกฤษของ PLO จากที่เล่มเขียน (เล่มมีครบ 13 ข้อแล้ว) | — |
| `clo_levels.md` | ระดับ I/R/M ราย CLO ต่อวิชาเอก | ISS-01 |
| `clo_fixes.md` | CLO ที่ต้องเขียนใหม่ (13012, 13018) | ISS-03, ISS-04 |
| `course_fixes.md` | รหัส/ชื่อ/วิชาบังคับก่อน/คำอธิบายที่ผิดหรือขาด | ISS-10…14 |
| `elective_majors.md` | วิชาชีพเลือกกลุ่มใดแนะนำให้วิชาเอกใด | ISS-17 |

ทุกแถวที่ override ต้องมีคอลัมน์ `ISS` อ้างรหัสใน [[04_Issues_Register]] เพื่อให้สืบย้อนได้ว่าแก้เพราะอะไร
