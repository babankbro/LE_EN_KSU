### 7.2 Admission
- **7.2.1 คุณสมบัติ**:
  1. ม.6 สายวิทยาศาสตร์–คณิตศาสตร์ or ศิลป์–คำนวณ, or ปวช. สาขาวิชาช่างกลโรงงาน / สาขาวิชาโลจิสติกส์ or equivalent, plus university announcement criteria.
  2. ปวส. สาขาวิชาการจัดการโลจิสติกส์และซัพพลายเชน / เทคนิคการผลิต / เทคนิคอุตสาหกรรม or equivalent — admitted via credit transfer (เทียบโอนผลการเรียน) under ระเบียบมหาวิทยาลัยกาฬสินธุ์ ว่าด้วยหลักเกณฑ์การเทียบโอนหน่วยกิตและผลการศึกษา พ.ศ. 2566 and ข้อบังคับสภาวิศวกร.
  3. Other qualifications per university announcement or คณะกรรมการบริหารหลักสูตร.
- **7.2.2 Selection**: per university admission system/rounds; may use GPA, written exam, interview, or portfolio.
- **7.2.3 Entry problems**: uneven math/statistics/programming background; insufficient technical English; adjusting to project-based, team-based, self-directed learning.
- **7.2.4 Remedies**: orientation + baseline assessment; prep activities linked to NS-541-11001 คณิตศาสตร์วิศวกรรม 1, NS-541-11002 คณิตศาสตร์วิศวกรรม 2, EN-710-11006 ความน่าจะเป็นและสถิติวิศวกรรม, EN-710-11002 การโปรแกรมคอมพิวเตอร์ (codes do appear in หมวด 4); advisor for every student, close monitoring of year-1; technical-English activities, peer tutoring, academic clinics.

## B. หมวดที่ 8 กระบวนการประเมินหลักสูตร

### 8.1 Program performance evaluation (7 steps)
Committee meets every semester. Steps: (1) start-of-term committee meeting on CLO–PLO results (% attainment per PLO); (2) student satisfaction analysis (online survey; means/proportions); (3) teaching quality (e-Evaluation, Peer Review); (4) education statistics (graduation, enrolment, dropout from registrar); (5) stakeholder voice (Focus Group, employer survey; Thematic Analysis); (6) IQA/EQA results (SAR, AUN-QA) → 1–3 year development plan; (7) annual development Action Plan.

### 8.2 Year-level YLO assessment
All YLOs: direct, individual assessment; **criterion uniformly "Analytic Rubric 4 ระดับ: ≥3/4 ทุกองค์ประกอบสำคัญ"**.

| Year | YLOs | Example tools |
|---|---|---|
| 1 | IE-YLO1.1–1.3; SC-YLO1.1–1.3 | ข้อสอบอัตนัยคำนวณ, ข้อสอบกรณีศึกษาระบบงาน/โซ่อุปทาน, แบบทดสอบปฏิบัติงานฝึกฝีมือ, แบบทดสอบปฏิบัติคอมพิวเตอร์ |
| 2 | IE-YLO2.1–2.5; SC-YLO2.1–2.3 | ข้อสอบออกแบบจากกรณีศึกษา, ข้อสอบออกแบบการทดลอง, ข้อสอบวิเคราะห์เชิงปริมาณ, แบบประเมินสถานการณ์จำลอง, ข้อสอบวิเคราะห์สินทรัพย์, ข้อสอบสถานการณ์บูรณาการ |

Total: 6 + 8 + 9 + 4 = 27 YLOs.

### 8.3 PLO assessment process (7 steps)
CLO–PLO Mapping → assessment tasks per CLO → record scores per CLO → synthesize PLO level (**"สรุป % ของนักศึกษาที่บรรลุ PLO (≥ 50%)"**) → LOA Report each semester → improve low PLOs → re-assess next cycle (PDCA). Responsibility: lecturers, ประธานหลักสูตร, secretary, committee.

### 8.4 PLO assessment table (13 PLOs: LE1–4, IE1–5, SC1–4)
- All direct, individual, via mapped YLOs; criterion "Rubric 4 ระดับ ≥3/4 ทุกองค์ประกอบสำคัญ; น้ำหนักรวม 100% ต่อ PLO".
- Timing: PLO_LE1 → Y1S2 and Y4S1; PLO_LE2–LE4 → Y4S1 only (YLO4.2–4.4); IE PLOs → Y1S2/Y2S2/Y3S2 combos; SC PLOs → Y2S2 and Y3S2.
- Mapping highlights: PLO_LE1 ← IE-YLO1.1, 1.2, SC-YLO1.1–1.3, YLO4.1; PLO_IE1 ← IE-YLO2.1, 3.1, 3.2, 3.4; PLO_IE2 ← IE-YLO1.3, 2.2, 3.3; PLO_IE3 ← IE-YLO2.3, 3.4; PLO_IE4 ← IE-YLO2.4, 3.1; PLO_IE5 ← IE-YLO1.3, 2.5, 3.2, 3.4; PLO_SC1 ← SC-YLO2.1, 2.2, 3.1, 3.2; PLO_SC2 ← SC-YLO2.3, 3.3; PLO_SC3 ← SC-YLO2.2, 2.3, 3.2, 3.3, 3.4; PLO_SC4 ← SC-YLO2.3, 3.5.

### 8.5 Course-level CLO assessment (7 steps)
Define CLO & Rubric → design activities/tasks → teach & assess → % attaining each CLO → course report → reflect in course-group/committee meeting → course improvement plan.

### 8.6 Satisfaction/stakeholder evaluation (5 steps)
Survey design (students; teaching, content, lecturers, resources, atmosphere) → e-Form collection → external stakeholders (employers, alumni; questionnaire + Focus Group; graduate competence, skill gaps) → statistical + thematic analysis → report via SAR/AUN-QA.

### 8.7 Complaints and grade appeals
- Complaints: online form/advisor; fact-finding committee; **reply within 15 working days**; logged per semester.
- Grade appeal per ประกาศมหาวิทยาลัยกาฬสินธุ์ เรื่อง การอุทธรณ์ผลการเรียนของนักศึกษา พ.ศ.2568: file within **7 working days** of grade release → lecturer checks within **7 working days** → คณะกรรมการพิจารณาอุทธรณ์และร้องทุกข์ decides within **15 working days** of receipt → notify within **3 working days** → recorded each semester end.

### 8.8 Follow-up of evaluation results (6 steps)
Summarize all evaluations (end of semester) → committee meeting (≥ 1 per semester) → Action Plan (immediately) → assign owners (within 1 week) → implement/measure next semester → report to คณะ/สำนักส่งเสริมวิชาการและงานทะเบียน each semester.

### 8.9 Curriculum communication (9 processes)
PLO announcement (annual, ประธานหลักสูตร); CLO via Syllabus (each semester); orientation (start of year); assessment methods (each semester); CLO–PLO dashboard (mid/end of term); stakeholder forum (1–2 times/year, QA unit); PR via website/Facebook/YouTube (continuous); SAR/Annual Report (yearly); individual advising via e-Advisor (each semester).

## D. หมวดที่ 9 แผนกลยุทธ์การบริหารคุณภาพหลักสูตร ระยะ 5 ปี (ปีการศึกษา 2570–2574)

### 9.1 Executive summary
