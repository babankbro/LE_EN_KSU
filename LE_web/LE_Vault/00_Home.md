## คำสั่งที่ใช้บ่อย (รันที่ราก `LE_web/`)

```bash
python tools/extract_curriculum.py      # เล่ม .docx → data/curriculum.json
python tools/build_vault.py             # curriculum.json → LE_Vault/10_Curriculum/
python tools/check_vault_links.py       # ตรวจลิงก์เสียในวอลต์
npm run dev --prefix web                # เว็บ http://localhost:5173 (สร้างข้อมูลเว็บให้อัตโนมัติ)
```
