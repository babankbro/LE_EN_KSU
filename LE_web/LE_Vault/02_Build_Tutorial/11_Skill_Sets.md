# ขั้นที่ 11 · ชุดทักษะ 6 ชุดสำหรับ Skill Transcript

> **เป้าหมาย: ทำให้ชุดทักษะในข้อ 4.6 เป็นข้อมูลที่ชี้กลับไปยังรายวิชา CLO และ PLO ได้จริง แทนที่จะเป็นตารางข้อความที่อ้างชื่อวิชาลอย ๆ**

| หลักสูตร → รายวิชา | `/courses/:code` | ป้ายชุดทักษะที่รายวิชานั้นรองรับ |

## ข้อมูลจริงของหลักสูตรนี้

ตรวจจาก `data/curriculum.json` → `skillSets.header` (7 คอลัมน์) และ `skillSets.rows` (18 แถว = 1 แถวต่อทักษะย่อย ข้อมูลระดับชุดซ้ำทุกแถว) เทียบกับ [[04c_ch4_studyplan_mapping_skills]]

| รหัส | ชื่อชุด (Skill Transcript) | ประเภท | ระดับทักษะย่อย 1/2/3 | CLO ที่อ้าง | PLO ที่ไปถึงจริง |
|---|---|---|---|---:|---|
| LE-SK01 | การคิดวิเคราะห์และแก้ปัญหาอย่างเป็นระบบ | Soft | 3 / 3 / 3 | 5 | LE1 |
| LE-SK02 | การสื่อสารทางวิชาชีพและการทำงานเป็นทีม | Soft | 3 / 2 / 3 | 8 | LE3 |
| IE-SK01 | การวิเคราะห์และปรับปรุงกระบวนการผลิต | Hard | 3 / 3 / 3 | 8 | IE1, IE5 |
| IE-SK02 | การใช้เครื่องมือและแบบจำลองทางวิศวกรรมอุตสาหการ | Hard | 2 / 3 / 3 | 7 | IE1, IE3 |
| SC-SK01 | การวางแผนและเพิ่มประสิทธิภาพโซ่อุปทาน | Hard | 3 / 3 / 3 | 9 | LE1, SC1, SC2 |
| SC-SK02 | การวิเคราะห์ข้อมูลโลจิสติกส์เพื่อสนับสนุนการตัดสินใจ | Hard | 2 / 3 / 3 | 5 | LE1, SC3 |

- รวม **6 ชุด · 18 ทักษะย่อย · 42 การอ้าง CLO** (34 คู่ วิชา–CLO) คอลัมน์ "PLO ที่ไปถึงจริง" คำนวณจาก `mapping` ของ CLO ที่อ้าง ไม่ได้มาจากเล่ม
- เล่มอ้าง **ชื่อวิชา ไม่ใช่รหัส** เช่น "การวิจัยการดำเนินงาน (CLO2, CLO3)" ต้องแปลงชื่อเป็นรหัสเอง ทุกชื่อแปลงได้ครบเมื่อตัดช่องว่าง
- ระดับใช้ "ระดับ 2 (ประยุกต์ใช้)" และ "ระดับ 3 (วิเคราะห์และบูรณาการ)" แต่เล่มไม่ได้นิยามสเกลทั้งหมด และหัวคอลัมน์บอก "เทียบเคียงกับมาตรฐาน" โดยไม่ระบุมาตรฐานใด
- ช่องว่างของความครอบคลุม: ชุดทักษะไม่แตะ **LE2, LE4, IE2, IE4, SC4**
- **SC-SK01 ข้อ 3** (Transportation Planning) อ้าง 13018 CLO1, 2, 5 และ **SC-SK02 ข้อ 3** อ้าง 13018 CLO4 ซึ่งข้อความ CLO ของ 13018 ในแผนที่ 4.5 ถูกคัดลอกมาจากแล็บอัตโนมัติ 13010 (ISS-04) ส่วนใน 4.3 เป็นเรื่องขนส่ง/จราจร — ชุดทักษะจึงชี้ไปยังข้อความคนละชุดขึ้นกับว่าใช้ส่วนใดของเล่ม

## Prompt A · วอลต์

```text
งาน: แปลงตาราง 4.6.1 เป็นข้อมูลชุดทักษะที่สืบย้อนได้ ครอบคลุมชุดร่วม (LE) และ 2 วิชาเอก (IE, SC)
ราก = LE_web/

1. แก้ tools/extract_curriculum.py เพิ่มผลลัพธ์ skillSetsParsed (เก็บ skillSets.rows เดิมไว้ด้วย)
   [{ code, name, nameEn, group, type, major: "ALL"|"IE"|"SC",
      subs: [{ n, name, nameEn, level, levelLabel, desc,
               clos: [{ courseName, code, clo }], tools, assessment }] }]
   - major จากคำนำหน้า: LE- → ALL · IE- → IE · SC- → SC
   - แยก "1. ชื่อ (English) — ระดับ 3 (วิเคราะห์และบูรณาการ): คำอธิบาย" เป็น n/name/nameEn/level/levelLabel/desc
   - แยกคอลัมน์ CLO ด้วย pattern "<ชื่อวิชา> (CLO1, CLO2)" แล้วแปลงชื่อเป็นรหัสโดยเทียบกับ
     courses[].th หลังตัดช่องว่าง ถ้าไม่พบให้ลองตาราง alias ใน LE_Vault/overrides/course_fixes.md
     (field = alias) ถ้ายังไม่พบให้เก็บ code: null (ห้ามเดารหัส)
   - แยก "เครื่องมือ:" กับ "การประเมิน:" ในคอลัมน์สุดท้ายออกเป็น tools / assessment
   - พิมพ์: ชุด · ทักษะย่อย · การอ้าง CLO · ชื่อวิชาที่แปลงไม่ได้   ค่าอ้างอิง 6 · 18 · 42 · 0
   - throw error เมื่อได้ 0 ชุด หรือชุดใดมีทักษะย่อย 0 ข้อ
   issue derived ใน build-data.mjs:
     "skillCourseUnresolved"  code เป็น null
     "skillCloMissing"        CLO ที่อ้างไม่มีใน courses[code].clos หรือวิชาไม่อยู่ในแผนของวิชาเอกของชุด
     "skillCloSuspect"        (code, clo) ตรงกับแถวที่มี issue cloText 4.5 ≠ 4.3
                              ค่าอ้างอิง: SC-SK01 ข้อ 3 และ SC-SK02 ข้อ 3 (13018)

2. tools/build_vault.py ขยายโน้ต 10_Curriculum/SkillSets/<code>.md 6 ไฟล์ที่ขั้นที่ 2 สร้างไว้
   frontmatter: type: skillset · code · major · plo: [คำนวณจาก mapping] · level_max
   เนื้อหา: ตารางทักษะย่อย | ระดับ | CLO ที่อ้าง ([[EN-788-13006]] CLO2) | เครื่องมือ | วิธีประเมิน
   และในดัชนี 10_Curriculum/SkillSets/00_SkillSets_Index.md เพิ่ม
     ตาราง 1 ชุด × PLO (✓ เมื่อมี CLO ที่อ้างไปถึง PLO นั้นในวิชาเอกของชุด)
     ตาราง 2 PLO ที่ไม่มีชุดทักษะใดรองรับ แยก IE / SC
   พิมพ์จำนวนโน้ตที่เขียน (ต้องได้ 6 + ดัชนี 1)
```

> [!tip] ชุดทักษะกับ PLO พูดกับคนละกลุ่ม
> PLO เขียนให้ผู้ประเมินคุณภาพอ่าน ส่วนชุดทักษะเขียนให้นายจ้างอ่าน ช่อง "PLO ที่ไปถึงจริง" จึงต้องคำนวณจาก CLO ที่อ้าง เพื่อพิสูจน์ว่าทักษะที่พิมพ์ลง transcript มีการประเมินรองรับในหลักสูตรจริง

## Prompt B · เว็บ

```text
1. web/scripts/build-data.mjs ขยาย web/src/generated/skills.js ที่ขั้นที่ 2 สร้างไว้
   export const SKILL_SETS = [{ code, name, nameEn, group, type, major, plos: [], subs: [...] }]
   export const COURSE_SKILLS = { [courseCode]: [skillCode] }   // ย้อนจาก subs[].clos
   - plos คำนวณจาก MAPPING[major] (ชุด LE ใช้ทั้ง IE และ SC) ห้ามพิมพ์เอง
   - ลงทะเบียน kind skill* ทั้งสามใน web/src/warnings.js
   - ตรวจว่า web/src/codeInfo.js (ขั้นที่ 2) มีรหัส SK ครบ 6 และชื่อเต็มมาจาก SKILL_SETS (FR-20)
   - พิมพ์ "skills 6 ชุด · 18 ทักษะย่อย · 42 CLO refs · issue n"

2. สร้าง web/src/pages/Skills.jsx และ route /skills ในเมนู "ผลลัพธ์การเรียนรู้"
   section sets     การ์ด 1 ใบต่อชุด สี Soft/Hard ต่างกัน
                    หัวการ์ด: รหัส ชื่อไทย ชื่ออังกฤษ กลุ่มทักษะ ป้าย PLO (คลิกไป /plo/:id)
                    รายการทักษะย่อย: ชื่อ · แถบระดับ (2 หรือ 3) · CLO เป็น chip "13006·CLO2" คลิกไป /courses/:code
                    เครื่องมือและวิธีประเมิน
                    CLO ที่มี issue → chip สีส้ม + <WarnBadge kind="skillCloSuspect"/> (ISS-04)
   section matrix   ตารางชุด × PLO 13 ข้อ ช่อง = จำนวน CLO ที่อ้าง
                    PLO ที่ไม่มีชุดใดรองรับให้หัวคอลัมน์เป็นสีเทาพร้อมข้อความ "ไม่มีชุดทักษะรองรับ"
   section scale    <WarnBadge kind="noSkillScale"/> เล่มใช้ระดับ 2–3 แต่ไม่ได้นิยามสเกลและไม่ระบุมาตรฐานที่เทียบ
   วิชาเอกจาก useMajor(): IE แสดง LE+IE · SC แสดง LE+SC · ALL แสดงทั้ง 6 ชุด

3. CourseDetail.jsx เพิ่มแถว "ชุดทักษะที่รองรับ" จาก COURSE_SKILLS พร้อมเลข CLO
4. ลบส่วน ⑤ ชุดทักษะ AISK ใน Obe.jsx ของ template หรือเปลี่ยนให้ลิงก์มาที่ /skills
```

- [ ] chip ของ 13018 ใน SC-SK01 ข้อ 3 และ SC-SK02 ข้อ 3 เป็นสีส้มพร้อมป้ายเตือน
- [ ] เมทริกซ์แสดงว่า LE2, LE4, IE2, IE4, SC4 ไม่มีชุดทักษะรองรับ
- [ ] ชี้ที่รหัส `IE-SK02` ที่หน้าใดก็ได้แล้วมี tooltip ชื่อชุดเต็ม
- [ ] `/courses/EN-788-13006` แสดงว่ารองรับ IE-SK02 (CLO1–4)
- [ ] โน้ต 6 ไฟล์ใน `10_Curriculum/SkillSets/` มีตารางทักษะย่อยและ `plo:` ใน frontmatter และ broken link = 0

> [!warning] กับดักที่พบในเล่มนี้
> - **13018 ผิดสองชั้น (ISS-04):** CLO ใน 4.5 เป็นของแล็บอัตโนมัติ 13010 แต่ชุดทักษะ SC ด้านขนส่งและข้อมูลเชิงพื้นที่อ้าง 13018 ถ้าเขียน CLO ใหม่แล้ว ต้องกลับมาตรวจว่าเลข CLO ที่ชุดทักษะอ้างยังสื่อความเดิมหรือไม่
> - **อ้างด้วยชื่อวิชา:** ชื่อในเล่มมีช่องว่างแทรกจากการตัดบรรทัด และสหกิจศึกษามีสองชื่อ ("ด้าน…" ใน 4.2 กับ "สำหรับ…" ในแผน) การเทียบแบบตรงตัวจะหาไม่เจอ
> - **18 แถวไม่ใช่ 18 ชุด:** ข้อมูลระดับชุดซ้ำทุกแถว ต้อง group ด้วยรหัสก่อนนับ
> - **ชุดทักษะ SC อ้างวิชาร่วม** (12002, 12004, 12005) ซึ่งส่ง PLO_LE1 ไม่ใช่ PLO วิชาเอก ทำให้ดูเหมือนครอบคลุมกว่าที่เป็นจริง
> - **ไม่มีสเกลและมาตรฐานอ้างอิง:** ห้ามเติมคำนิยามระดับ 1–4 เองบนเว็บ ให้แสดงป้ายว่าเล่มไม่ได้นิยาม
> - **"......" ค้างในบทนำ 4.6.1 (ISS-53)** ถ้าดึงบทนำมาแสดงต้องตัดหรือแสดงป้าย
