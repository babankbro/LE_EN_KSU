# ขั้นที่ 7 · 90 รายวิชา คำอธิบายไทย/อังกฤษ และ CLO

> **เป้าหมาย: ทุกรายวิชาเปิดดูได้ครบทั้งคำอธิบาย CLO และ Bloom พร้อม YLO/PLO ตามวิชาเอก — และทุกจุดที่เล่มขาดหรือผิดต้องมีป้ายเตือน ไม่ใช่ช่องว่าง**

## หลังจบขั้นนี้ต้องได้อะไร

| เมนู | เส้นทาง | เนื้อหา |
|---|---|---|
| หลักสูตร → รายวิชา | `/courses` | ค้นหารหัส/ชื่อไทย/อังกฤษ · กรองกลุ่ม วิชาเอก ชั้นปี PLO · จำนวนที่ตรงเงื่อนไข · ป้ายเตือนบนการ์ด |
| หลักสูตร → รายวิชา | `/courses/:code` | หน่วยกิต `n(l-p-s)` · กลุ่ม · วิชาเอก · ภาคที่เรียน · คำอธิบายสองภาษา · CLO + Bloom + YLO/PLO ตามวิชาเอก · วิชาบังคับก่อน/ต่อยอด |

**SRS ที่ครอบคลุม:** FR-05 · FR-06 · FR-21 · VR-01–03 (โน้ตรายวิชาฉบับเต็ม) · DP-07 ดู [[03_SRS_Curriculum_Website]] และแถว 🟠 ใน [[02_Checklist_Web_Data]]

## Prompt A · วอลต์

```text
ขยายโน้ตรายวิชาใน tools/build_vault.py (ราก = LE_web/) ให้ครบ 90 ไฟล์ใน LE_Vault/10_Curriculum/Courses/

1. โครงโน้ต <code>.md
   frontmatter: type: course · code · group · credits · major · year · plo · bloom: [ค่าภาษาอังกฤษ]
                flags: [...] · generated: true
   - ชื่อไทย / ชื่ออังกฤษ / หน่วยกิต / กลุ่ม (ลิงก์ [[<group-id>]] ใน Structure/)
   - ภาคที่เรียน: ตาราง วิชาเอก | ปี | ภาค (ไม่มีในแผน = "เลือกเรียน")
   - คำอธิบายไทย · คำอธิบายอังกฤษ · วิชาบังคับก่อน (ข้อความเล่มทั้งไทยและอังกฤษ + [[ลิงก์]])
   - ตาราง CLO: n | ข้อความ | Bloom | YLO (IE) | PLO (IE) | ระดับ (IE) | YLO (SC) | PLO (SC) | ระดับ (SC)
     วิชาเฉพาะวิชาเอกให้แสดงเฉพาะคอลัมน์ของวิชาเอกนั้น
2. ป้ายเตือนในโน้ต (callout > [!warning]) ตามตาราง "จุดที่ต้องมีป้ายเตือน" ของขั้นที่ 7
   ตรวจอัตโนมัติจากข้อมูล ไม่ใช่พิมพ์รายการรหัสลงสคริปต์ ยกเว้นกรณีที่อยู่ใน overrides/clo_fixes.md
3. เติม LE_Vault/overrides/clo_fixes.md (target | field | value | ISS | หมายเหตุ)
   ใส่แถวสำหรับ EN-788-13012#CLO1, #CLO2 และ EN-788-13018#CLO1–5 (แผนที่ 4.5) โดย value = "รอกรรมการเขียนใหม่"
   ห้ามแต่ง CLO ใหม่เอง ระบบจะติดป้าย "CLO อาจคัดลอกผิดวิชา" จนกว่า value จะเป็นข้อความจริง
4. ก่อนเติม overrides/course_fixes.md ของ GE-002-14003, 14013, 14015 ให้เปิดเล่ม .docx ตรวจว่าคำอธิบาย
   ถูกรวมอยู่ในเซลล์ชื่อวิชาหรือไม่ ถ้าพบให้คัดข้อความจากเล่มลง override พร้อม ISS-14
   ถ้าไม่พบจริงจึงปล่อยว่างให้ป้าย "ไม่มีในเล่ม" แสดง
5. LE_Vault/10_Curriculum/Courses/00_Courses_Index.md (generated: true)
   ตาราง รหัส | ชื่อไทย | ชื่ออังกฤษ | หน่วยกิต | กลุ่ม | วิชาเอก | ปี/ภาค IE | ปี/ภาค SC | จำนวน CLO | ป้าย
   จัดหัวข้อตามกลุ่ม และสรุปจำนวนวิชา/CLO ต่อกลุ่ม
6. throw ถ้าได้วิชาไม่ครบ 90 หรือ CLO ไม่ครบ 254 · พิมพ์จำนวนต่อกลุ่ม จำนวนวิชาที่มีป้ายแยกตามชนิด
```

## Prompt B · เว็บ

```text
1. ใน web/scripts/build-data.mjs ให้ COURSES (web/src/generated/courses.js) มีรูป
   { code, th, en, credits, cr: { n, l, p, s }, group, majors, plan: { IE?, SC? },
     descTh, descEn, prereq, prereqTh, prereqEn, codeAsPrinted?,
     clos: [{ n, th, bloom, bloomEn, map: { IE?, SC? }, flags: [] }], plos, flags: [] }
   - แยก cr จาก "n(l-p-s)" ด้วย regex · ถ้า parse ไม่ได้ให้ throw พร้อมรหัสวิชา
   - bloomEn = คำในวงเล็บของ bloom
   - ติด flags: noDescTh · noDescEn · noClo · cloUnmapped · cloDuplicate · cloMapMismatch ·
     cloCopied (จาก clo_fixes.md) · enDescDuplicated · codeAsPrinted
   - พิมพ์จำนวนวิชาต่อ flag
2. เพิ่มข้อความใน web/src/warnings.js (ที่เดียวทั้งเว็บ)
   noDescTh "ไม่มีคำอธิบายรายวิชาภาษาไทยในเล่ม" · noDescEn "ไม่มีคำอธิบายภาษาอังกฤษในเล่ม" ·
   noClo "เล่มไม่ได้กำหนด CLO" · cloUnmapped "CLO ยังไม่เชื่อมกับ YLO/PLO" ·
   cloCopied "CLO อาจคัดลอกผิดวิชา" · cloMapMismatch "ข้อความ CLO ในแผนที่ 4.5 ไม่ตรงกับคำอธิบายรายวิชา" ·
   cloDuplicate "CLO ข้อความเดียวกับวิชาอื่น" · enDescDuplicated "คำอธิบายภาษาอังกฤษซ้ำสองรอบ" ·
   codeAsPrinted "เล่มพิมพ์รหัสเป็น …"
3. หน้า web/src/pages/Courses.jsx (/courses)
   - ช่องค้นหาเทียบรหัส ชื่อไทย ชื่ออังกฤษ (normalise ช่องว่าง ไม่สนตัวพิมพ์)
   - ตัวกรอง: กลุ่ม (จาก GROUPS) · ชั้นปี (จาก plan ของวิชาเอกที่เลือก) · PLO (จาก plos) · "มีป้ายเตือน"
   - วิชาเอกใช้ useMajor() ไม่ใช่ตัวกรองแยก: IE แสดง majors ที่มี IE
   - เก็บคำค้นและตัวกรองใน URL (q, group, year, plo) คู่กับ ?major=
   - แสดงจำนวนที่ตรงเงื่อนไขเสมอ · การ์ดแสดงป้าย flag เป็นจุดสีพร้อม title
4. หน้า web/src/pages/CourseDetail.jsx (/courses/:code)
   - code ไม่สนตัวพิมพ์ · ถ้าเป็น codeAsPrinted (NS-531-1100) ให้ redirect ไปรหัสที่ถูก · ไม่พบ → NotFound
   - หัว: รหัส ชื่อไทย/อังกฤษ หน่วยกิตแยก บรรยาย-ปฏิบัติ-ศึกษาด้วยตนเอง · กลุ่ม · ป้ายวิชาเอก
   - ภาคที่เรียน: ของวิชาเอกที่เลือก (ALL แสดงทั้งสอง) · ไม่มีในแผน = "เลือกเรียน"
   - คำอธิบายไทย/อังกฤษ: ถ้าว่างให้ <WarnBadge kind="noDescTh|noDescEn"/> แทนกล่องเปล่า
     ถ้ามี override ให้ <OverrideBadge target={code} field="descTh"/>
   - ตาราง CLO: n · ข้อความ · Bloom (สีตาม bloomEn) · YLO และ PLO ของวิชาเอกที่เลือก
     (ALL = คอลัมน์ IE และ SC) · ระดับ (ว่าง = <WarnBadge kind="noLevel"/>) · ป้าย flag ราย CLO
     กรณี cloMapMismatch ให้แสดงข้อความ CLO จาก 4.3 และข้อความที่ต่างใน 4.5 คู่กัน
   - วิชาบังคับก่อนเป็นลิงก์ /courses/:code · "วิชาที่ต่อยอด" คำนวณย้อนจาก prereq ของวิชาอื่น
     รหัสที่ไม่มีในรายการ (เช่น EN-001-007) แสดงเป็นข้อความพร้อมป้ายเตือน
5. ลงทะเบียนรหัสวิชาทั้ง 90 ใน codeInfo.js ให้ป้ายรหัสวิชาทุกจุดในเว็บมี tooltip และคลิกได้
```

> [!important] ป้ายเตือนต้องมาจากข้อมูล ไม่ใช่รายการรหัสในโค้ด
> ถ้าเขียน `if (code === "EN-788-13018")` ในหน้าเว็บ เมื่อกรรมการแก้เล่มแล้วป้ายจะยังค้าง ให้ทุกป้ายมาจาก `flags` ที่ build-data คำนวณ หรือจากแถวใน `overrides/` ที่มี ISS กำกับ

> - **13012 กับ 13018 ผิดคนละแบบ** 13012 ผิดตั้งแต่ 4.3 (CLO ของ 13013) ส่วน 13018 ถูกใน 4.3 แต่ผิดในแผนที่ 4.5 (CLO ของ 13010) ถ้าตรวจแค่จุดเดียวจะพลาดอีกวิชา และชุดทักษะ SC-SK01/SC-SK02 ยังอ้าง CLO ของ 13018 ที่ผิดนี้ (ขั้นที่ 11)

> - **คำผิดในชื่อและคำอธิบาย** เช่น "ซอฟแวร์" ในชื่อ 14002 (ISS-49) ช่องค้นหาควรค้นได้ทั้งคำที่ถูกและคำที่เล่มสะกด จึงไม่ควรแก้คำในข้อมูล
> - **`1(1-0-3)` ของ EN-710-11009** ต่างจากวิชาบรรยาย 1 หน่วยกิตอื่นที่ใช้ `1(1-0-2)` (ISS-51) ตัว parse ต้องรับได้ และ `6(0-40-0)` ของสหกิจศึกษาก็ต้อง parse ได้เช่นกัน
