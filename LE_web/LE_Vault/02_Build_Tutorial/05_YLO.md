## ข้อมูลจริงของหลักสูตรนี้

**จำนวน YLO** (`ylos[]`, รหัสแบบ string)

| วิชาเอก | ปี 1 | ปี 2 | ปี 3 | ปี 4 | รวม |
|---|:-:|:-:|:-:|:-:|:-:|
| IE (`IE-YLO1.1…3.4`) | 3 | 5 | 4 | — | 12 |
| SC (`SC-YLO1.1…3.5`) | 3 | 3 | 5 | — | 11 |
| ร่วม (`YLO4.1–4.4`, `major: "ALL"`) | — | — | — | 4 | 4 |

นักศึกษา IE รับผิดชอบ 16 ข้อ (12 + 4) และ SC 15 ข้อ (11 + 4) · `yloIntro` มี 7 ข้อความนำ คีย์ `IE-1` `IE-2` `IE-3` `SC-1` `SC-2` `SC-3` `ALL-4` · PLO ที่สนับสนุนดึงมาจากวงเล็บ "(สนับสนุน PLO_…)" ท้ายถ้อยคำ

**ความครอบคลุมชั้นปี × PLO ตามนิยาม YLO** (✓ = มี YLO ของปีนั้นสนับสนุน)

| PLO | IE ปี 1 | IE ปี 2 | IE ปี 3 | ปี 4 | SC ปี 1 | SC ปี 2 | SC ปี 3 |
|---|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| LE1 | ✓ | | | ✓ | ✓ | | |
| LE2 | ✓ | | | ✓ | | | |
| LE3 | | | | ✓ | | | |
| LE4 | | | | ✓ | | | |
| IE1–IE4 | | ✓ | ✓ | | — | — | — |
| IE5 | ✓ | ✓ | ✓ | | — | — | — |
| SC1–SC4 | — | — | — | | | ✓ | ✓ |

- **LE3 และ LE4 มี YLO เฉพาะปี 4** ทั้งสองวิชาเอก · LE2 ของ SC มีเฉพาะปี 4 (ISS-20)
- **ปี 4 ไม่มี PLO ของวิชาเอกเลย** YLO4.1–4.4 ผูกกับ LE1–LE4 เท่านั้น
- SC ปี 1 ทั้ง 3 ข้อสนับสนุน LE1 อย่างเดียว · IE-YLO1.3 (ปี 1) สนับสนุน IE5 ซึ่งเป็นเรื่องนวัตกรรมจากปัญหาจริง

**ในแผนที่ 4.5 (นับจาก `mapping`)**

| ตรวจ | IE | SC |
|---|---:|---:|
| แถวที่ผูก YLO4.x | 36 | 34 |
| ในจำนวนนั้น เป็นรายวิชาปี 1 หรือปี 3 | **30** | **28** |
| ค่า YLO สะกดเพี้ยน `"YLO4.3 ("` | 1 | 0 |
| `IE-YLO1.1` / `SC-YLO1.1` (แถว / วิชา) | 28 / 10 | 25 / 9 |
| `YLO4.3` (แถว / วิชา หลัง normalise) | 15 / 7 | 15 / 7 |
| `YLO4.1` (แถว / วิชา) | 1 / 1 | 1 / 1 |
| แถวที่ PLO ในแถว **ไม่อยู่ใน** `plos` ของ YLO นั้น | **31** | **30** |

กล่าวคือ เล่ม "เติม" LE2–LE4 ให้ปี 1–3 ด้วยการผูก CLO ปี 1/ปี 3 เข้ากับ YLO ของปี 4 ไม่ใช่ด้วย YLO ของปีนั้น

แถวที่ PLO ขัดกับนิยาม YLO ส่วนใหญ่เป็น PLO_LE1 ที่ผูกผ่าน YLO ของวิชาเอก เช่น IE: `IE-YLO2.3`→LE1 13 แถว · `IE-YLO2.1`→LE1 8 · `IE-YLO3.1`→LE1 7 · `IE-YLO1.3`→IE2 3 และ SC: `SC-YLO2.2`→LE1 13 · `SC-YLO2.1`→LE1 8 · `SC-YLO3.3`→LE1 7 · `SC-YLO3.5`→LE2 2

## Prompt A · วอลต์

```text
ขยาย tools/build_vault.py ส่วนโน้ต YLO (ราก = LE_web/) ต้องรองรับ IE, SC และ ALL

1. LE_Vault/10_Curriculum/YLO/<id>.md 27 ไฟล์ (ชื่อไฟล์ = id เช่น IE-YLO2.3.md, YLO4.1.md)
   - frontmatter: type: ylo · code · major (IE|SC|ALL) · year · plo: [...] · generated: true
   - ข้อความนำของปีนั้นจาก yloIntro["<major>-<year>"] (ปี 4 ใช้ "ALL-4")
   - ถ้อยคำ YLO และลิงก์ [[PLO_...]]
   - ตาราง "รายวิชาที่ส่งเข้า" จาก mapping หลัง normalise ค่า YLO
     (ตัดช่องว่างและ "(" ค้างท้าย) แยกหัวข้อวิชาเอก IE และ SC สำหรับ YLO4.x
     คอลัมน์: ปีของวิชา/ภาค | [[รหัสวิชา]] | CLO | PLO | ระดับ
     ถ้าปีของวิชาไม่ตรงกับปีของ YLO ให้ใส่ ⚠ ในคอลัมน์ปี
2. LE_Vault/10_Curriculum/YLO/00_YLO_Matrix.md (generated: true)
   - เมทริกซ์ ชั้นปี × PLO สองตาราง (IE: LE1–4 + IE1–5 · SC: LE1–4 + SC1–4)
     ช่องที่ไม่มี YLO สนับสนุนให้เขียน "—" และสรุปใต้ตาราง
   - ตาราง "YLO ปี 4 ที่ถูกผูกกับรายวิชาปี 1–3" นับแยก YLO และวิชาเอก
   - รายการค่า YLO ที่ต้อง normalise พร้อมจำนวนแถว
3. ดัชนี 00_YLO_Index.md จัดหัวข้อ IE ปี 1–3 · SC ปี 1–3 · ร่วมปี 4 พร้อมข้อความนำรายปี
4. throw ถ้า YLO ได้ไม่ครบ 27 หรือมี YLO ใน mapping (หลัง normalise) ที่ไม่มีใน ylos[]
   พิมพ์จำนวน YLO ต่อวิชาเอก/ปี · ช่องว่างในเมทริกซ์ต่อวิชาเอก · จำนวนแถวที่ปีไม่ตรง
```

> [!important] normalise ที่จุดเดียว
> ให้ฟังก์ชัน normalise YLO อยู่ใน `build-data.mjs` และ `build_vault.py` ด้วยกฎเดียวกัน แล้ว **throw เมื่อค่าที่ normalise แล้วยังไม่ตรงกับ YLO ใดเลย** ห้ามกรองแถวทิ้งเงียบ ๆ เพราะจะทำให้ YLO4.3 ของ IE เหลือ 14 แถวแทน 15

## Prompt B · เว็บ

```text
1. ใช้ YLOS, YLO_BY_ID, YLO_INTRO จาก web/src/generated/ylos.js และ MAPPING จาก generated/mapping.js
   (build-data.mjs normalise ค่า YLO ใน MAPPING แล้ว และเก็บค่าเดิมไว้ใน ylRaw ของแถวที่ถูกแก้)
2. web/src/outcomes.js เพิ่มฟังก์ชัน
   ylosOfMajor(major)        IE → IE-* + YLO4.* · SC → SC-* + YLO4.* · ALL → ทั้งหมด
   coverage(major)           { [year]: { [ploId]: [yloId] } } คำนวณจาก YLOS
   rowsOfYlo(id, major)      แถว MAPPING ที่ ylo === id (YLO4.x ต้องดูทั้งสองวิชาเอกเมื่อ ALL)
3. หน้า web/src/pages/Ylos.jsx (/ylo)
   - ใช้ useMajor(): IE หรือ SC แสดงคอลัมน์เดียว ปี 1→4 · ALL แสดง IE กับ SC เคียงกัน
     โดยปี 4 เป็นแถวเดียวกว้างเต็ม (YLO ร่วม)
   - แต่ละปี: ข้อความนำจาก YLO_INTRO แล้วตามด้วยการ์ด YLO ที่มีป้าย PLO สีจาก PLO_COLOR
   - เมทริกซ์ ชั้นปี × PLO จาก coverage() ห้ามพิมพ์ตารางด้วยมือ
     ช่องว่างของ PLO ร่วมในปี 1–3 ให้ใช้ <WarnBadge kind="yloGap"/> และแถว "ปี 4" ที่ไม่มี PLO วิชาเอก
     ให้ขึ้น <WarnBadge kind="noMajorPloY4"/>
   - แถบตรวจบนหน้า: PLO ที่มี YLO เฉพาะปี 4 · YLO ที่ไม่มีแถวในแผนที่ · จำนวนแถวที่ผูกข้ามชั้นปี ·
     จำนวนแถวที่ PLO ไม่อยู่ใน plos ของ YLO (<WarnBadge kind="yloPloMismatch"/>)
4. หน้า web/src/pages/YloDetail.jsx (/ylo/:id)
   - หา id แบบไม่สนตัวพิมพ์ (ie-ylo2.3 → IE-YLO2.3) แล้ว redirect แบบ replace โดยคง ?major=
   - ไม่พบ → NotFound · ถ้า YLO เป็นของอีกวิชาเอก แสดงแถบบอกและลิงก์สลับวิชาเอก
   - ส่วนหัว: ถ้อยคำ · ข้อความนำของปีนั้น · ป้าย PLO ที่คลิกไป /plo/:id
   - "รายวิชาที่ส่งเข้า" จาก rowsOfYlo() จัดกลุ่มตามปี/ภาคจริงของรายวิชา
     ถ้าปีของรายวิชา ≠ ปีของ YLO ใส่ <WarnBadge kind="yloYearMismatch"/>
     ถ้าแถวนั้นถูก normalise (มี ylRaw) ใส่ป้ายเล็ก "ค่าในเล่ม: YLO4.3 ("
     ถ้าระดับว่าง ใช้ <WarnBadge kind="noLevel"/> เหมือนขั้นที่ 4
     ถ้า PLO ของแถวไม่อยู่ใน plos ของ YLO นี้ ใส่ <WarnBadge kind="yloPloMismatch"/>
5. เพิ่ม YLO ทั้ง 27 ข้อใน codeInfo.js · ป้าย YLO ทุกจุดคลิกไป /ylo/:id
6. ตรวจ route ที่มีจุด: เปิด /ylo/IE-YLO1.1 ตรง ๆ และกด refresh ทั้งใน npm run dev และ npm run preview
   ถ้าได้ 404 ให้ใช้ encodeURIComponent ตอนสร้างลิงก์ หรือเปลี่ยน path เป็น slug ที่แทน "." ด้วย "-"
```

- [ ] เมทริกซ์ IE มีป้ายช่องว่างที่ LE3 และ LE4 ปี 1–3 · เมทริกซ์ SC มีเพิ่มที่ LE2 ปี 1–3
- [ ] แถว "ปี 4" ของทั้งสองวิชาเอกมีป้าย "ไม่มี PLO ของวิชาเอก"
- [ ] `/ylo/IE-YLO1.1?major=IE` แสดง 28 แถวจาก 10 รายวิชา
- [ ] `/ylo/YLO4.3?major=IE` แสดง 15 แถว 7 รายวิชา และมีหนึ่งแถวที่ติดป้าย "ค่าในเล่ม: YLO4.3 ("
- [ ] `/ylo/YLO4.4?major=SC` มีแถวของรายวิชาปี 1 และปี 3 ที่ติดป้ายผูกข้ามชั้นปี
- [ ] แถบตรวจบน `/ylo?major=IE` นับแถวผูกข้ามชั้นปีได้ 30 และ `?major=SC` ได้ 28
- [ ] แถบตรวจนับแถวที่ PLO ขัดกับนิยาม YLO ได้ IE 31 · SC 30 และ `/ylo/IE-YLO2.3?major=IE` มีป้ายนี้ 13 แถว
- [ ] เปิด `/ylo/SC-YLO3.5` ตรง ๆ แล้ว refresh ไม่ได้ 404 ทั้งใน dev และ preview
- [ ] ใน Obsidian `00_YLO_Matrix` ไม่มีลิงก์เสีย และลิงก์ `[[YLO4.3]]` เปิดโน้ตได้

> [!warning] กับดักที่พบในเล่มนี้
> - **รหัส YLO ไม่สม่ำเสมอ** ปี 1–3 มีคำนำหน้า `IE-`/`SC-` แต่ปี 4 เป็น `YLO4.x` ไม่มีคำนำหน้า (ISS-52) ต้องให้ `major: "ALL"` และให้ YLO4.x ปรากฏในทั้งสองวิชาเอก
> - **YLO4.x ถูกผูกกับรายวิชาปี 1 และปี 3** (IE 30 แถว · SC 28 แถว) เช่น ปฏิบัติการเคมีพื้นฐานส่ง CLO เข้า YLO4.2/YLO4.3 ถ้าจัดกลุ่มรายวิชาตามปีของ YLO จะได้ภาพผิดว่าปี 4 มีวิชาจำนวนมาก
> - **คู่ YLO–PLO ในแผนที่ 4.5 ไม่ตรงกับนิยาม YLO ในข้อ 3.2** 61 แถว (IE 31 · SC 30) เช่น IE-YLO2.3 นิยามว่าสนับสนุน IE3 แต่ 13 แถวส่งเข้า LE1 ถ้า roll-up PLO ผ่าน YLO จะได้ผลไม่เท่ากับ roll-up จากช่อง PLO ของแถว ให้ใช้ช่อง PLO ของแถวเป็นหลักและแสดงป้ายเตือน
> - **ค่า `"YLO4.3 ("`** ในแผนที่ IE หนึ่งแถว ถ้าไม่ normalise จะเกิดทั้งลิงก์เสียในวอลต์และแถวหายจากหน้า `/ylo/YLO4.3`
> - **วิชาเดียวกันส่ง CLO เข้า YLO คนละข้อในแต่ละวิชาเอก** เช่น 12003 CLO3–4 เข้า YLO4.2 ในแผน IE แต่เข้า SC-YLO3.5 ในแผน SC ห้ามใช้แผนที่ของวิชาเอกหนึ่งแทนอีกวิชาเอก
> - **จำนวน YLO ต่อปีไม่เท่ากัน** IE ปี 2 มี 5 ข้อ แต่ SC ปี 2 มี 3 ข้อ และ SC-YLO2.3 รับ PLO ถึง 3 ข้อ layout แบบตารางคู่ขนานต้องรองรับจำนวนการ์ดไม่เท่ากัน
> - **สำนวนท้ายประโยคไม่เหมือนกัน** YLO ของ SC และปี 4 ลงท้ายด้วย "…ได้" แต่ของ IE ไม่มี ให้แสดงตามเล่ม ไม่ต้องปรับถ้อยคำ
> - **เลขหัวข้อในเล่มกระโดดจาก "1)" ไป "2.1–2.3"** (ISS-45) ตัวดึงใช้ข้อความ "2.1 ผลลัพธ์การเรียนรู้รายปีของวิชาเอก…" เป็น anchor ถ้าเล่มแก้เลขหัวข้อต้องแก้ตัวดึงตาม
