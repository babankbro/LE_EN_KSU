# ขั้นที่ 8 · วิชาบังคับก่อนและกราฟรายวิชา

> **เป้าหมาย: เปลี่ยน "วิชาบังคับก่อน" ที่เล่มเขียนเป็นข้อความ ให้เป็นเส้นเชื่อมที่เครื่องตรวจได้ และชี้ว่าเส้นใดที่เล่มเขียนผิด**

| หลักสูตร → กราฟรายวิชา | `/graph` | กราฟ dagre ของวิชาที่มีความสัมพันธ์ก่อน–หลัง กรองตามวิชาเอก |

- มีเพียง **11 จาก 90 วิชา** ที่ `prereq[]` ไม่ว่าง (บวก 14006 ที่ตัวดึงจับรหัสไม่ได้)
- ตัวดึงรุ่นปัจจุบันรวมรหัส TH+EN จึงได้ 11006 = `["NS-541-11002","NS-541-11001"]` เป็น 12 เส้นดิบ หลังเลือกฝั่งไทยเหลือ **11 เส้น (hard 9 · coreq 2)**
- แยกวิชาเอก: **IE 17 โหนด 11 เส้น · SC 13 โหนด 8 เส้น** (13002/13003/13006/13007 เป็นวิชาเอก IE) และเพิ่มอย่างละ 1 เมื่อ override 14006
- สายยาวสุด 4 ชั้น: NS-541-11001 → NS-541-11002 → EN-710-11006 → EN-788-13003/13006 (IE)
- ถูกอ้างมากสุด: NS-533-11001 → 3 วิชา (11002, 11004, 11007) · EN-710-11006 → 2 วิชา (3 เมื่อแก้ 14006)
- เส้น hard ทุกเส้นมีวิชาต้นทางอยู่ภาคก่อนหน้าจริงในแผนของทั้งสองวิชาเอก

## Prompt A · วอลต์

```text
งาน: ทำวิชาบังคับก่อนให้เป็นข้อมูลที่ตรวจได้ รองรับ 2 วิชาเอก (IE, SC)  ราก = LE_web/

1. แก้ tools/extract_curriculum.py ส่วน "prerequisite codes → links"
   - normalise CRLF และช่องว่างก่อน parse (เล่มมี "NS-541-11001คณิตศาสตร์วิศวกรรม 1" ติดกัน)
   - parse prereqTh กับ prereqEn แยกกัน ห้ามรวมเป็น set เดียว
     เก็บ courses[].prereqCodes = { th: [...], en: [...] } และใช้ฝั่งไทยเป็นค่าเริ่มต้นจนกว่าจะมี override
   - ข้อความมี "หรือเรียนควบคู่กัน" / "or Study concurrently" → kind "coreq" นอกนั้น "hard"
     courses[].prereq = [{ code, kind, src: "th"|"en"|"plan" }]
   - จับรหัสรูปแบบเดิม [A-Z]{2}-\d{3}-\d{3} ด้วย เก็บไว้ใน prereqLegacy: ["EN-001-007"]
   - พิมพ์จำนวนวิชาที่มี prereq · จำนวนเส้นแยก hard/coreq
     ค่าอ้างอิง: 11 วิชา · 11 เส้น (hard 9, coreq 2)
   - throw error เมื่อได้ 0 วิชา
   การสร้าง issue ให้ทำใน build-data.mjs เป็น origin "derived" ตามแนวของ [ขั้นที่ 2]
   (TH/EN ไม่ตรงกัน → 11006 · อ้างรหัสเดิม → 14006) ห้ามสร้างซ้ำทั้งสองที่

2. เพิ่มแถวใน LE_Vault/overrides/course_fixes.md
   | code | field | ค่าในเล่ม | ค่าที่ใช้ | ISS |
   | EN-710-11006 | prereq | NS-541-11002 / NS-541-11001 | NS-541-11002 | ISS-12 |
   | EN-788-14006 | prereq | EN-001-007 | EN-710-11006 | ISS-13 |
   ค่าที่ใช้ต้องให้กรรมการหลักสูตรยืนยัน ถ้ายังไม่ยืนยันให้เขียน "รอยืนยัน" ห้ามเดาเอง

3. tools/build_vault.py สร้าง LE_Vault/10_Curriculum/Prerequisites.md (generated: true)
   และเพิ่มลิงก์ใน 10_Curriculum/00_Curriculum_Index.md
   ตาราง 1: รหัสวิชา | ชื่อวิชา | ชนิด | วิชาก่อน | ภาค IE | ภาค SC | ที่มา (เล่ม/override) | ISS
   ตาราง 2 วิชาที่ต่อยอด: รหัสวิชา | จำนวนวิชาที่อ้าง | รายการวิชา
   ใน 10_Curriculum/Courses/<code>.md เพิ่ม frontmatter prereq: [...] และหัวข้อ "วิชาบังคับก่อน" /
   "วิชาที่ต่อยอด" เป็น wikilink [[รหัสวิชา]]  ห้ามทำ wikilink ไปยัง EN-001-007 (ลิงก์เสีย)
   พิมพ์จำนวนแถวของทั้งสองตาราง
```

## Prompt B · เว็บ

```text
1. web/scripts/build-data.mjs เขียน web/src/generated/prereq.js
   export const PREREQ_EDGES = [{ from, to, kind, majors: ["IE","SC"], source: "book"|"override", iss }]
   export const REVERSE = { [code]: [รหัสวิชาที่ต่อยอด] }   // คำนวณจาก edges ห้ามพิมพ์เอง
   - เพิ่ม issue origin "derived" เข้า ISSUES (generated/issues.js ของขั้นที่ 2):
     "prereqLangMismatch" (11006 · ISS-12) และ "prereqLegacyCode" (14006 · ISS-13)
     แล้วลงทะเบียน kind ทั้งสองใน web/src/warnings.js
   - majors ของเส้น = วิชาเอกที่ปลายทั้งสองอยู่ในแผน (ใช้ PLANS.IE / PLANS.SC)
   - throw เมื่อพบ: hard ที่ต้นทางไม่อยู่ภาคก่อนหน้าในแผนเดียวกัน · รหัสที่ไม่มีใน courses · วงจร
   - พิมพ์ "prereq IE 11 เส้น/17 โหนด · SC 8/13"

2. web/src/graphLayout.js  export layoutGraph(major, scope)
   - dagre rankdir "LR" ให้คอลัมน์สะท้อนภาค (ใช้โหนดล่องหน sem-1…sem-8 เป็นแกน
     หรือคำนวณ x จากภาคเองแล้วให้ dagre จัดเฉพาะแนวตั้ง) หน้าเว็บกับสคริปต์ตรวจต้องเรียกฟังก์ชันนี้ตัวเดียวกัน
   - scope "linked" (ค่าเริ่ม) เฉพาะวิชาที่มีเส้น · "all" ทุกวิชาในแผนของวิชาเอกนั้น

3. เขียน web/src/DependencyGraph.jsx ใหม่ (เลิก import ../data.js ของ template)
   - อ่านวิชาเอกด้วย useMajor() (web/src/major.js ของขั้นที่ 1) แล้วกรองเส้นตาม majors
   - hard เส้นทึบมีหัวลูกศร · coreq เส้นประไม่มีหัว · source "override" สีส้ม + <OverrideBadge target field="prereq"/>
   - สีกล่องตาม GROUPS ของ generated/structure.js ลบโหมด plo/track ของ template
   - คลิกโหนดไฮไลต์ทั้งสาย · ปุ่ม "เปิดรายวิชา" → /courses/:code (ใช้ withMajor())
   - ใต้กราฟแสดง <WarnBadge kind="prereqLangMismatch"/> และ "prereqLegacyCode" จาก ISSUES

4. web/src/pages/CourseDetail.jsx
   วิชาบังคับก่อน: chip ลิงก์ + ชนิด + <WarnBadge/> เมื่อ TH/EN ไม่ตรงหรือเป็นรหัสเดิม
   วิชาที่ต่อยอด: จาก REVERSE ถ้าว่างเขียน "ไม่มีวิชาใดกำหนดวิชานี้เป็นวิชาบังคับก่อน"

5. web/scripts/check-graph.mjs (เรียกจาก npm run check)
   เรียก layoutGraph ทุกชุด IE/SC/ALL × linked/all แล้วตรวจกล่องทุกคู่ว่าไม่ซ้อนกัน (AABB)
   พิมพ์ "overlap IE=0 SC=0 ALL=0" และ exit 1 ถ้าค่าใดไม่เป็น 0
```

## ตรวจรับ

- [ ] ตัวดึงพิมพ์ 11 วิชา · 11 เส้น (hard 9, coreq 2) และ `ISSUES` มีรายการ derived ของ 11006 และ 14006
- [ ] `/graph?major=IE` แสดง 17 โหนด 11 เส้น · `?major=SC` 13 โหนด 8 เส้น (ก่อน override 14006)
- [ ] มุมมอง SC ไม่มี 13002/13003/13006/13007
- [ ] แล็บ 11002 ทั้งสองวิชาเป็นเส้นประ และตัวตรวจภาคไม่ขึ้น error
- [ ] `node web/scripts/check-graph.mjs` พิมพ์ overlap = 0 ทุกชุด
- [ ] `/courses/EN-710-11006` และ `/courses/EN-788-14006` มีป้ายเตือน (หรือป้าย "แก้ไขจากเล่ม" เมื่อ override แล้ว)
- [ ] `/courses/NS-533-11001` แสดงวิชาที่ต่อยอด 3 วิชา
- [ ] `python tools/check_vault_links.py` ได้ broken=0

> [!warning] กับดักที่พบในเล่มนี้
> - **EN-710-11006 (ISS-12):** ไทยอ้าง NS-541-11002 แต่อังกฤษเขียนรหัส 11001 คู่กับชื่อ "Mathematics 2" ถ้ารวมสองภาษาเป็น set เดียว ความผิดนี้จะกลายเป็น "วิชาบังคับก่อนสองวิชา" ที่ดูถูกต้อง
> - **EN-788-14006 (ISS-13):** อ้าง `EN-001-007` regex `\d{4,5}` จับไม่ได้ วิชานี้จึงหลุดจากกราฟโดยไม่มี issue
> - **แล็บ "หรือเรียนควบคู่กัน"** อยู่ภาคเดียวกับวิชาบรรยาย ถ้าถือเป็น hard ตัวตรวจภาคจะแจ้ง error ปลอม
> - **วิชาเอกไม่เท่ากัน:** ถ้าไม่กรองตามแผน SC จะเห็นเส้นห้อยไปยังวิชาเอก IE
> - **อย่าเติมเส้นที่เล่มไม่มี:** 13018 (แล็บขนส่ง SC) กับ 14006 (ทฤษฎีขนส่ง วิชาเลือก) เนื้อหาซ้อนกันแต่ไม่มีวิชาบังคับก่อน ให้บันทึกเป็นข้อสังเกต ดู [[04b_ch4_major_courses]]
> - **กราฟเบาบาง:** โหมด "ทุกวิชา" มีโหนดเดี่ยว 22 (IE) และ 24 (SC) โหนด จึงตั้งค่าเริ่มเป็นเฉพาะวิชาที่มีเส้น
