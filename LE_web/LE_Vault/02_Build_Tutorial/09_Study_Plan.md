# ขั้นที่ 9 · แผนการเรียน 8 ภาค × 2 วิชาเอก

> **เป้าหมาย: แสดงแผนการเรียนของ IE และ SC ให้ยอดรายภาคและยอดสะสมคำนวณจากรายวิชาจริง และเห็นทันทีว่าภาคใดผิดปกติ**

## Prompt A · วอลต์

```text
งาน: สร้างแผนการเรียนในวอลต์จาก data/curriculum.json รองรับ 2 วิชาเอก (IE, SC)  ราก = LE_web/

1. ตรวจใน tools/extract_curriculum.py (ต่อจากส่วน 4.4)
   - plans.IE และ plans.SC ต้องมี 8 ภาคพอดี ถ้าไม่ใช่ throw error; ถ้าภาคใดมี 0 รายวิชา throw error
   - ทุกภาค: ผลรวมจากรายวิชา = credits ที่ระบุ และ cumulative ต่อเนื่อง ถ้าไม่ตรง → issues[] (มีอยู่แล้ว)
   - รหัสที่มี "x" (GE-002-140xx, EN-788-14xxx, EN-788-15xxx) ให้ placeholder: true
     และผูกกับกลุ่ม ge-elec / el-* / free ห้ามนับเป็นรายวิชาที่ไม่มีใน 4.2
   - พิมพ์: ภาคต่อวิชาเอก · รายวิชาจริง/placeholder ต่อวิชาเอก · ยอดรวม IE/SC
   การเทียบชื่อ (ตัดช่องว่าง) และรูปแบบหน่วยกิต n(l-p-s) ระหว่างแผนกับ courses[] ให้ทำใน
   build-data.mjs เป็น issue derived kind "planMismatch" (ค่าอ้างอิงตอนนี้ 4 จุด)

2. tools/build_vault.py สร้าง LE_Vault/10_Curriculum/Study_Plan_IE.md และ Study_Plan_SC.md
   (generated: true และลิงก์จาก 00_Curriculum_Index.md)
   ตารางรายภาค 8 ตาราง: หมวดวิชา | รหัสวิชา | ชื่อวิชา (ใช้ชื่อจาก 4.2) | หน่วยกิต | วิชาบังคับก่อน/เรียนควบคู่ | หมายเหตุ
   ท้ายตารางทุกภาค: "รวม n หน่วยกิต · สะสม m"
   รหัสวิชาจริงเป็น wikilink [[EN-788-12001]] ส่วน placeholder เขียนเป็นข้อความ ห้ามทำลิงก์
   ปิดท้ายด้วยตารางเทียบ: ภาค | IE | สะสม IE | SC | สะสม SC | ภาระต่ำกว่าเกณฑ์?
   เกณฑ์ภาระขั้นต่ำอ่านจาก LE_Vault/overrides/plan_rules.md (min_regular_load: รอยืนยัน)
   ถ้ายังไม่มีค่า ให้เขียนว่า "ยังไม่ได้ตรวจกับข้อบังคับ" ห้ามใส่ตัวเลขเอง

3. ใน 10_Curriculum/Courses/<code>.md เพิ่ม frontmatter plan: { IE: "1/2", SC: "1/2" } (ไม่อยู่ในแผนเขียน null)
```

> [!tip] ใช้ชื่อวิชาจาก 4.2 เสมอ
> แผนการเรียนในเล่มพิมพ์ชื่อซ้ำอีกรอบและเพี้ยนไปบ้าง ให้ถือรายการ 4.2 เป็นชื่อหลัก แล้วเก็บชื่อที่ต่างไว้เป็นหลักฐานใน issue เท่านั้น

## Prompt B · เว็บ

```text
1. web/scripts/build-data.mjs ขยาย web/src/generated/plans.js ที่ขั้นที่ 2 สร้างไว้
   export const PLANS = { IE: [{ year, sem, credits, cumulative,
                                 stated: { credits, cumulative },
                                 courses: [{ code, placeholder, group, credits, cr, nameTh }] }],
                          SC: [...] }
   export const YEAR_CREDITS = { IE: [..4], SC: [..4] }   // คำนวณ
   - credits/cumulative คำนวณใหม่จากรายวิชา ส่วนค่าที่เล่มพิมพ์เก็บใน stated
   - nameTh ใช้ชื่อจาก COURSE_BY_CODE ไม่ใช่ชื่อที่พิมพ์ในแผน
   - เพิ่ม issue derived kind "planMismatch" และ "lowLoad" เข้า ISSUES แล้วลงทะเบียน kind ใน warnings.js
   - cr = เลขหน้าวงเล็บของ credits ("3(x-x-x)" → 3, "6(0-40-0)" → 6)
   - throw ถ้าผลรวมของวิชาเอกใดไม่เท่ากับ meta.totalCredits (122)
   - พิมพ์ "plan IE 8 ภาค 122 · SC 8 ภาค 122"

2. ปรับ web/src/PlanBoard.jsx ของ template ให้รับ props { major }
   - เลิก import ../data.js และเลิกแนวคิดแผน ก/แผน ข ของ template — ที่นี่สลับด้วยวิชาเอก
   - 8 คอลัมน์จัดเป็น 4 ปี · หัวคอลัมน์ = ปี/ภาค + ยอดที่คำนวณสด + ยอดสะสม
     ถ้ายอดคำนวณ ≠ stated ให้ขึ้นป้ายแดงที่หัวคอลัมน์นั้น
   - ภาคที่ต่ำกว่า min_regular_load (ถ้ามีค่าแล้ว) ขึ้น <WarnBadge kind="lowLoad"/> "ภาระต่ำ — ตรวจกับข้อบังคับ (ISS-21)"
     ถ้ายังไม่มีค่าให้ขึ้นป้ายเฉพาะปี 3/2 ว่า "ยังไม่ได้ตรวจภาระขั้นต่ำ"
   - การ์ดสีตามกลุ่มวิชา (groups[].id) · placeholder เป็นการ์ดเส้นประ คลิกไป /structure/<group>
   - การ์ดวิชาจริงคลิกไป /courses/:code · วิชาเฉพาะวิชาเอกมีป้าย IE หรือ SC
   - key ของการ์ด = `${code}-${index}` เพราะ EN-788-15xxx และ GE-002-140xx ซ้ำในภาคเดียวกัน
   - grid ใช้ minmax(0,1fr) และเลื่อนแนวนอนได้เฉพาะในกล่องกระดานบนจอ 375px

3. web/src/pages/Plan.jsx
   - อ่านวิชาเอกด้วย useMajor(): IE หรือ SC แสดงกระดานเดียว · ALL แสดงตารางเทียบรายภาค
     (ภาค | IE | SC | วิชาที่ต่างกัน) แล้วตามด้วยกระดานสองวิชาเอกเรียงกัน
   - แถบสรุป: รวม 122 ✓ · ยอดรายปี · จำนวนวิชาจริง/ช่องเลือก (ตัวเลขทุกตัวคำนวณจาก PLANS)
   - <WarnBadge kind="planMismatch"/> ที่การ์ดวิชาที่ชื่อหรือหน่วยกิตในแผนไม่ตรงกับ 4.2
   - ปุ่มส่งออก CSV ของแผนวิชาเอกที่เลือก (FR-23)

4. CourseDetail.jsx แสดง "เรียนในแผน: IE ปี 2/2 · SC —" จาก PLANS
   วิชาชีพเลือกและ GE เลือก แสดง "เลือกเรียนในช่อง EN-788-14xxx ปี 4/2"
```

## ตรวจรับ

- [ ] ตัวดึงพิมพ์ 8 ภาคต่อวิชาเอก และยอดรวม IE 122 · SC 122
- [ ] `/plan?major=IE` หัวคอลัมน์เป็น 21 / 22 / 21 / 21 / 17 / 5 / 6 / 9 และสะสมสุดท้าย 122
- [ ] `/plan?major=SC` หัวคอลัมน์เป็น 20 / 22 / 21 / 18 / 19 / 7 / 6 / 9 และสะสมสุดท้าย 122
- [ ] ทดลองย้ายวิชาหนึ่งใน `curriculum.json` ฉบับทดสอบ → หัวคอลัมน์ขึ้นป้ายแดง และ build-data throw เมื่อยอดรวม ≠ 122
- [ ] ปี 3/2 มีป้ายภาระต่ำ หรือป้าย "ยังไม่ได้ตรวจภาระขั้นต่ำ"
- [ ] การ์ดช่องเลือกไม่ทำให้ React เตือน duplicate key ใน console
- [ ] `/courses/EN-788-13003` แสดง "IE ปี 2/2 · SC —"
- [ ] `/plan?major=ALL` เห็นชัดว่าภาค 1/1, 2/1, 2/2, 3/1, 3/2 ต่างกัน
- [ ] โน้ต `Study_Plan_IE.md` และ `Study_Plan_SC.md` มียอดตรงกับหน้าเว็บ และ broken link = 0

> [!warning] กับดักที่พบในเล่มนี้
> - **ภาคเบาผิดปกติ (ISS-21):** ปี 3/2 เหลือ 5–7 หน่วยกิต เพราะย้ายภาระไปไว้ปี 3/1 และปี 4 ให้แสดงเป็นป้าย ไม่ใช่ "แก้" แผนเอง
> - **ช่องเลือกใช้รหัสปลอม** `GE-002-140xx`, `EN-788-14xxx`, `EN-788-15xxx` ซ้ำกันในภาคเดียว ถ้า join กับ `courses[]` จะได้ undefined และถ้าใช้ code เป็น key จะชนกัน
> - **หน่วยกิตไม่เป็นรูป l-p-s ปกติ:** `3(x-x-x)` และ `6(0-40-0)` ของสหกิจ ตัว parse ต้องอ่านแค่เลขหน้าวงเล็บ
> - **แผนกับ 4.2 ไม่ตรงกัน 4 จุด** (12002, 13001, 13007, 17002) ใช้ 4.2 เป็นหลักและแสดงป้าย
> - **วิชาเอกต่างกันตั้งแต่ภาคแรก:** IE มี 13008 ใน 1/1 ส่วน SC ไม่มี template เดิมที่มีแผนเดียวจะทำให้ยอดปี 1/1 ของ SC ผิดถ้าคัดลอกตรรกะมา
> - **EN-710-11009 ใช้ 1(1-0-3)** ขณะที่วิชาบรรยาย 1 หน่วยกิตอื่นใช้ 1(1-0-2) (ISS-51) ไม่กระทบยอด แต่ควรขึ้นในหน้า `/data-quality`
